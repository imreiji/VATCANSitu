// SituCPDLC.txt - CPDLC message set and station identity for VATCANSitu.
//
// Same format as TopSkyCPDLC.txt, deliberately: the [STATIONS] block below started as a
// copy of the one CZQM already ships for TopSky, and a controller can paste theirs over
// it. Lines are // comments, Key=Value, or TYPE:field:field.
//
// LOGIN:<login>:<radio callsign>:<controller id>
//   <login>         the four character Hoppie station this facility logs on as
//   <radio callsign> the RTF callsign, sent in transfer and current-unit messages
//   <controller id>  the EuroScope position identifier, field 4 of an .ese [POSITIONS]
//                    line - the same value GetHandoffTargetControllerId returns
//
// Position identifiers are defined by the loaded sector file, not globally, so this
// table is only as good as the package it is read alongside. VATCANSitu reports at load
// how many positions in the current package resolve, and names the ones that do not.
//
// FACILITY:<callsign prefix>:<login>:<radio callsign>
//   Fallback for a position identifier that is not listed above - the controller is
//   running a different package, or a new sector split has been added and nobody has
//   updated this file. Matched against the part of the controller callsign before the
//   first underscore, so CZQM_2_CTR falls back to the Moncton entry. Without this a
//   split nobody anticipated resolves to nothing at all.

CPDLC_FSM_CLD_Header=<hour><min> <year2><month2><day> <adep> PDC <number> @<callsign>@
